# shortcut

### **Cheatsheet de Atajos para Visual Studio Code**

### **1. Gestión General del Editor**

| Acción | Windows/Linux | Descripción |
| --- | --- | --- |
| Pantalla completa | F11 | Usa vscode en pantalla completa |
| Abrir/Cerrar terminal | `Ctrl + Ñ | Muestra u oculta el terminal integrado. |
| Abrir nuevo archivo | Ctrl + N | Crea un archivo nuevo en blanco. |
| Guardar archivo | Ctrl + S | Guarda el archivo actual. |
| Guardar todo | Ctrl + K, S | Guarda todos los archivos abiertos. |
| Cerrar pestaña | Ctrl + W | Cierra el archivo actual. |
| Abrir paleta de comandos | Ctrl + Shift + P | Accede a todos los comandos de VS Code. |
| Cambiar entre pestañas | Ctrl + Tab | Navega entre archivos abiertos. |

### **2. Edición de Código**

| Acción | Windows/Linux | Descripción |
| --- | --- | --- |
| Comentar línea | Ctrl + / | Comenta o descomenta la línea seleccionada. |
| Seleccionar línea completa | Ctrl + L | Selecciona toda la línea donde está el cursor. |
| Duplicar línea | Ctrl + Shift + D | Duplica la línea actual o la selección. |
| Mover línea arriba/abajo | Alt + ↑/↓ | Mueve la línea actual arriba o abajo. |
| Copiar línea arriba/abajo | Shift + Alt + ↑/↓ | Copia la línea actual arriba o abajo. |
| Seleccionar todas las ocurrencias | Ctrl + Shift + L | Selecciona todas las instancias de la palabra bajo el cursor. |
| Multicursor | Alt + Click | Añade cursores adicionales para editar múltiples líneas. |
| Formatear documento | Alt + Shift + F | Aplica formato automático al archivo (si tenes pluggins). |

**Aprendizaje**: Usa el **multicursor** (Alt + Click) para editar varias líneas al mismo tiempo, ideal para cambios repetitivos en código.

### **3. Navegación en el Código**

| Acción | Windows/Linux | Descripción |
| --- | --- | --- |
| Buscar en archivo | Ctrl + F | Busca texto dentro del archivo actual. |
| Ir a línea | Ctrl + G | Salta a una línea específica del archivo. |
| Buscar en proyecto | Ctrl + Shift + F | Busca texto en todos los archivos del proyecto. |
| Ir al archivo (navegar entre muchos archivos) | Ctrl + P | Abre un archivo rápidamente por su nombre. |
| buscar símbolos (funciones, clases, etc.) | Ctrl + T | Despliega un buscador de bloques de codigo |

### **4. Gestión de Paneles y Ventanas**

| Acción | Windows/Linux | Descripción |
| --- | --- | --- |
| Dividir editor | Ctrl + \ | Divide la ventana del editor en dos. |
| Cambiar entre editores divididos | Ctrl + 1/2/3 | Cambia el enfoque entre pestañas divididas. |
| Alternar barra lateral | Ctrl + B | Muestra u oculta la barra lateral. |
| Abrir explorador de archivos | Ctrl + Shift + E | Enfoca el explorador de archivos. |
